# Графический калькулятор математических выражений (C++ / Qt 6)

Проект представляет собой кроссплатформенное графическое приложение для вычисления сложных математических выражений. Данное приложение умеет разбирать цельные математические строки с учётом приоритета операторов и вложенности скобок.

## Архитектура и как это устроено

Логика вычислений полностью отделена от графического интерфейса (принцип разделения ответственности) и разбита на три независимых этапа:

1. **Токенизация (Лексический анализ):** 
   Входная строка из текстового поля графического интерфейса автоматически разбивается на вектор токенов (`std::vector<std::string>`). На этом этапе калькулятор корректно объединяет многозначные и дробные числа, а также изолирует знаки операций. Реализована обработка **унарного минуса** (отрицательных чисел), система автоматически отличает его от бинарного знака вычитания на основе анализа контекста строки.

2. **Парсинг и преобразование в ОПН (Алгоритм Дейкстры):**
   Полученный массив токенов перестраивается в Обратную польскую нотацию (постфиксную запись) с помощью классического алгоритма «Сортировочной станции» Эдсгера Дейкстры. Для управления приоритетами операторов (`+`, `-`, `*`, `/`, `^`) и разбора вложенных скобок `()` задействована структура данных **Стек** (`std::stack<char>`). В итоговом ОПН-выражении полностью отсутствуют скобки, а знаки расставлены в строгом порядке их выполнения компьютером.

3. **Вычисление (Стек чисел):**
   Готовое ОПН-выражение вычисляется за один проход с использованием второго стека (`std::stack<double>`). При встрече числа оно помещается в стек, при встрече оператора — два верхних числа извлекаются, к ним применяется математическое действие, и результат возвращается обратно.

## Стек технологий
* **Язык программирования:** C++ (стандарт C++17)
* **Графический фреймворк:** Qt 6 (модуль Qt Widgets)
* **Система сборки:** CMake
* **Структуры данных (STL):** `std::vector`, `std::stack`, `std::string`

## Развитие проекта
Интерфейс калькулятора спроектирован в визуальном редакторе Qt Designer с использованием адаптивной верстки (Layouts), что позволяет элементам динамически подстраиваться под размеры окна без искажения пропорций.
